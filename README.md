# 🛒 Labaadho - E-commerce Platform

Labaadho is a modern full-stack e-commerce platform built with **Angular** and **Laravel**, designed to provide a fast, secure, and scalable online shopping experience.

---

## 🚀 Features

- 🛍️ Product catalog management
- 🛒 Shopping cart system
- 👤 User authentication & authorization
- 📦 Order management system
- 💳 Payment integration ready
- 🔐 Secure REST API with Laravel
- ⚡ Responsive UI built with Angular

---

## 🧱 Tech Stack

### Frontend
- Angular
- TypeScript
- HTML / CSS / SCSS

### Backend
- Laravel (PHP Framework)
- RESTful API
- MySQL Database
- Sanctum Authentication
